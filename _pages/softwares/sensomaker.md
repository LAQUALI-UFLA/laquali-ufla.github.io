**SensoMaker is a software tool for the acquisition and analysis of sensory test data.**

The software provides a comprehensive set of tools for sensory data acquisition, preference mapping, discrimination testing, temporal sensory analysis, multivariate analysis, and statistical evaluation.

## Data Acquisition
- Categorical scale
- Hedonic scale
- Linear structured scale
- Linear unstructured scale
- Time-Intensity (TI)
- Temporal Dominance of Sensations (TDS)
- Discrimination testing

## Data Analysis
- Internal Preference Mapping
- External Preference Mapping
- Three-way Internal Preference Mapping
- Three-way External Preference Mapping
- TI graphical analysis
- TDS graphical analysis
- TI parameters
- TDS parameters
- Basic statistics
- Analysis of variance (ANOVA)
- Tukey's test
- Dunnett's test
- Binomial test

## Tools
- Automatic data organization
- Consumer segmentation for preference mapping
- Polynomial regression
- Principal Component Analysis (PCA)
- Correspondence Analysis (CA)
- Hierarchical Cluster Analysis (HCA)
- Sequential Analysis of Wald

## Installation
SensoMaker was developed in the MATLAB environment.

Since SensoMaker is a standalone application, a MATLAB license is not required to run the software. However, the MATLAB Compiler Runtime (MCR) is required. MCR is freely available and provides the shared libraries necessary to run applications developed with MATLAB.

SensoMaker is available for Microsoft Windows (32-bit and 64-bit).

1. Download and install the **MATLAB Compiler Runtime (MCR)**:

   [Download MCR](https://www.dropbox.com/scl/fi/413gsdj747myotqo7m77u/MCRInstaller.exe?rlkey=wb6u5iir8zd9d1mlqdf0thwnx&st=82y878m8&dl=1)

2. Download and install **SensoMaker**:

   [Download SensoMaker](https://www.dropbox.com/scl/fi/c0pm7d3pmj1pxgwg72zz8/SensoMaker_1-95_setup.exe?rlkey=heioj2fz25fw4b3jmh8iarzl7&st=fniip3bb&dl=1)

## Running SensoMaker
The different SensoMaker modules can be accessed from the software's home screen.

A screen resolution of at least **1024 × 768 pixels** is recommended.

SensoMaker uses a **dot (`.`) as the decimal separator**.

For detailed instructions on using the software, please refer to the [SensoMaker User Guide](https://github.com/cleitonqmc/SensoMaker/blob/SensoMaker/SensoMaker.pdf).
