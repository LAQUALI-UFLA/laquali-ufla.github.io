- **Version 1.95**
  - Fixed bug in Cochran’s Q Test

- **Version 1.94**
  - New TDS curve parameters

- **Version 1.93**
  - Chi-Squared test
  - Cochran test
  - Check-All-That-Apply (CATA) data Acquisition
  - Check-All-That-Apply (CATA) data Analysis
  - Hypothesis result in binomial test
  - 10 attributes in TDS test
  - Area for TDS curves

- **Version 1.92**
  - Fixed bugs
  - Improvements in internal functions
  - Improvements in some results display

- **Version 1.91**
  - Improvements in TDS graphs
  - Bar graph for TDS profiles
  - Stop and save TDS data acquisition before preset time
  - Correspondence Analysis

- **Version 1.9**
  - Option for normal or binomial approach in TDS curve analysis
  - Clarification in settings for smoothing TDS curves
  - Clarification in settings for smoothing TI curves

- **Version 1.8**
  - Module for acquiring data on Discrimination Testing
  - Module for analizing data from Discrimination Testing
  - Tool for Binomial Test
  - Tool for Senquential Analysis of Wald
  - Option for 7-point scale in Category Scale module

- **Version 1.7**
  - Options for ANOVA 1-way and 2-way in the Basic Stats/ANOVA module
  - Fixed bug in TI_5% time-intensity parameter
  - User guide available

- **Version 1.6**
  - Fixed bug in smooth level in Time-Intensity analysis
  - Corrections in label parametros for TDS analysis
  - Field for instructions is available in all acquisition modules

- **Version 1.5**
  - Tukey and Dunnett tests were implemented in the Basic Stats/ANOVA module
  - Field for category labels was extended in the Category Scale module

- **Version 1.4**
  - Improved functions for category labels in the Category Scale module

- **Version 1.3**
  - Improved interfaces for Line Scale, Category Scale and Time-Intensity modules

- **Version 1.2**
  - Fixed bugs in screen resolution

- **Version 1.1**
  - Fixed bugs in screen resolution
