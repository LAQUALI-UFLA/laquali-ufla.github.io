- **Versão 1.95**
  - Correção de erro no teste Q de Cochran

- **Versão 1.94**
  - Novos parâmetros para as curvas TDS

- **Versão 1.93**
  - Teste Qui-quadrado
  - Teste de Cochran
  - Aquisição de dados Check-All-That-Apply (CATA)
  - Análise de dados Check-All-That-Apply (CATA)
  - Resultado do teste de hipótese binomial
  - Teste TDS com 10 atributos
  - Cálculo da área das curvas TDS

- **Versão 1.92**
  - Correção de erros
  - Melhorias nas funções internas
  - Melhorias na exibição de alguns resultados

- **Versão 1.91**
  - Melhorias nos gráficos TDS
  - Gráfico de barras para os perfis TDS
  - Possibilidade de interromper e salvar a aquisição de dados TDS antes do tempo predefinido
  - Análise de Correspondência

- **Versão 1.9**
  - Opção de abordagem normal ou binomial na análise das curvas TDS
  - Esclarecimentos nas configurações de suavização das curvas TDS
  - Esclarecimentos nas configurações de suavização das curvas TI

- **Versão 1.8**
  - Módulo para aquisição de dados de testes de discriminação
  - Módulo para análise de dados de testes de discriminação
  - Ferramenta para o teste binomial
  - Ferramenta para a análise sequencial de Wald
  - Opção de escala de 7 pontos no módulo Escala de Categorias

- **Versão 1.7**
  - Opções de ANOVA de 1 e 2 fatores no módulo Estatística Básica/ANOVA
  - Correção de erro no parâmetro de tempo TI_5% da análise Tempo-Intensidade
  - Guia do usuário disponível

- **Versão 1.6**
  - Correção de erro no nível de suavização da análise Tempo-Intensidade
  - Correções nos rótulos dos parâmetros da análise TDS
  - Campo para instruções disponível em todos os módulos de aquisição

- **Versão 1.5**
  - Implementação dos testes de Tukey e Dunnett no módulo Estatística Básica/ANOVA
  - Ampliação do campo para rótulos de categorias no módulo Escala de Categorias

- **Versão 1.4**
  - Aprimoramento das funções para rótulos de categorias no módulo Escala de Categorias

- **Versão 1.3**
  - Aprimoramento das interfaces dos módulos Escala de Linha, Escala de Categorias e Tempo-Intensidade

- **Versão 1.2**
  - Correção de erros relacionados à resolução da tela

- **Versão 1.1**
  - Correção de erros relacionados à resolução da tela
