**O SensoMaker é uma ferramenta para aquisição e análise de dados de testes sensoriais.**

O software oferece um conjunto abrangente de ferramentas para aquisição de dados sensoriais, mapas de preferência, testes discriminativos, análise sensorial temporal, análise multivariada e avaliação estatística.

## Aquisição de Dados
- Escala categórica
- Escala hedônica
- Escala linear estruturada
- Escala linear não estruturada
- Tempo-Intensidade (TI)
- Dominância Temporal de Sensações (TDS)
- Testes discriminativos

## Análise de Dados
- Mapa de Preferência Interno
- Mapa de Preferência Externo
- Mapa de Preferência Interno de três vias
- Mapa de Preferência Externo de três vias
- Análise gráfica de TI
- Análise gráfica de TDS
- Parâmetros de TI
- Parâmetros de TDS
- Estatística básica
- Análise de variância (ANOVA)
- Teste de Tukey
- Teste de Dunnett
- Teste binomial

## Ferramentas
- Organização automática dos dados
- Segmentação de consumidores para mapas de preferência
- Regressão polinomial
- Análise de Componentes Principais (PCA)
- Análise de Correspondência (CA)
- Análise Hierárquica de Agrupamentos (HCA)
- Análise Sequencial de Wald

## Instalação
O SensoMaker foi desenvolvido no ambiente MATLAB.

Como o SensoMaker é uma aplicação independente, não é necessária uma licença do MATLAB para executar o software. No entanto, é necessário instalar o MATLAB Compiler Runtime (MCR). O MCR está disponível gratuitamente e fornece as bibliotecas compartilhadas necessárias para executar aplicações desenvolvidas em MATLAB.

O SensoMaker está disponível para Microsoft Windows (32 e 64 bits).

1. Baixe e instale o **MATLAB Compiler Runtime (MCR)**:

   [Baixar MCR (v7.16)](https://www.dropbox.com/scl/fi/413gsdj747myotqo7m77u/MCRInstaller.exe?rlkey=wb6u5iir8zd9d1mlqdf0thwnx&st=82y878m8&dl=1)

2. Baixe e instale o **SensoMaker**:

## Executando o SensoMaker
Os diferentes módulos do SensoMaker podem ser acessados a partir da tela inicial do software.

Recomenda-se uma resolução de tela de pelo menos **1024 × 768 pixels**.

O SensoMaker utiliza o **ponto (`.`) como separador decimal**.

Para obter instruções detalhadas sobre a utilização do software, acesse o User Guide por meio do menu **Help > User Guide** na tela inicial do software.
