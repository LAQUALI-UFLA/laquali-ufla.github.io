**O Chemoface é um software gratuito e de fácil utilização para análise quimiométrica e otimização de experimentos.**

O software oferece um conjunto abrangente de ferramentas para planejamento e otimização de experimentos, análise exploratória, calibração multivariada, classificação e pré-processamento de dados.

## Planejamento e Otimização de Experimentos
- Planejamento fatorial completo
- Planejamento fatorial fracionário
- Planejamento composto central
- Planejamento de Plackett–Burman
- Planejamento de misturas
- Função de desejabilidade

## Análise Exploratória
- Análise de Componentes Principais (PCA)
- Análise Hierárquica de Agrupamentos (HCA)

## Calibração Multivariada
- Regressão Linear Múltipla (MLR)
- Regressão por Componentes Principais (PCR)
- Mínimos Quadrados Parciais (PLS)

## Classificação
- MLR-DA
- PCR-DA
- PLS-DA

## Funcionalidades auxiliares
- Validação cruzada leave-one-out
- Seleção do conjunto de teste
- Gráficos de dados
- Construção de conjuntos de dados a partir de imagens moleculares `.bmp` para MIA-QSAR
- Importância da Variável na Projeção (VIP)

## Pré-processamento
- Centralização pela média
- Autoescalamento
- Suavização e derivadas
- Normalização
- Correção de espalhamento multiplicativo (MSC)
- Conversão espectral (absorbância/transmitância)
- Variável Normal Padrão (SNV)

## Instalação
O Chemoface foi desenvolvido no ambiente MATLAB.

Como o Chemoface é uma aplicação independente, não é necessária uma licença do MATLAB para executar o software. No entanto, é necessário instalar o MATLAB Compiler Runtime (MCR). O MCR está disponível gratuitamente e fornece as bibliotecas compartilhadas necessárias para executar aplicações desenvolvidas em MATLAB.

O Chemoface está disponível para Microsoft Windows (32 e 64 bits).

1. Baixe e instale o **MATLAB Compiler Runtime (MCR)**:

   [Baixar MCR (v7.16)](https://www.dropbox.com/scl/fi/413gsdj747myotqo7m77u/MCRInstaller.exe?rlkey=wb6u5iir8zd9d1mlqdf0thwnx&st=82y878m8&dl=1)

2. Baixe e instale o **Chemoface**:

   [Baixar Chemoface (v1.75)](https://www.dropbox.com/scl/fi/n3pdipmvvezxh7scecxkc/Chemoface_1-75_setup.exe?rlkey=34c235rt601ojo8lxgtl8iwak&st=w7hmvv9f&dl=1)

## Executando o Chemoface
Os diferentes módulos do Chemoface podem ser acessados a partir da tela inicial do software.

Recomenda-se uma resolução de tela de pelo menos **1024 × 768 pixels**.

O Chemoface utiliza o **ponto (`.`) como separador decimal**.

Para obter instruções detalhadas sobre a utilização do software, acesse o User Guide por meio do menu **Help > User Guide** na tela inicial do software.
